Robotics-Builder 🤖 — by mkuuCodes | Eldoret, KE

Robotics builder from Eldoret, Kenya building affordable bots with Arduino & ESP32.

### What I Build
- Line follower (IR sensors)
- Obstacle avoider (HC-SR04)
- ESP32 Home Automation
- Ream beam calculator

### Why This Repo?
In Eldoret, parts are expensive. I document real Kenya prices, wiring, and simple code so students can build without breaking the bank.

### Parts (Luthuli Ave Prices)
Arduino Uno: 2.5k | ESP32: 1.5k | HC-SR04: 400

### Goal
From Eldoret to Switzerland/Germany — prove world-class robotics can start in a small town. B1 Deutsch learner.
